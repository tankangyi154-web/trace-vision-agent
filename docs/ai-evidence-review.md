2026-11-03。用户选择“暂时没有真人，先完成AI复核”。本轮完成AI逐项复核与代码修复，真人独立评估作为可选后续，不作为这轮交付的前置条件。没有真人参与，不填写真人意见，也不将AI复核称为独立人工评估。

## 复核范围

- 11条历史真实响应，包含1条重复缓存响应；对应10条不同问题响应、8份素材。不是11个独立语义样本。
- AI查看代表性实际截图；程序另核对全部33处引用的记录归属、实际文件与目标编号，没有发现跨记录或编号错配。
- 对时长排名按连续采样段重新计算，人#1为15.2秒、汽车#36为7秒，与当时回答相符。结论仅在识别记录范围内成立，不证明真实世界唯一身份。
- 单独保留清晰图片、低清远景、密集人流、合成阴性对照、三张作者标注身高照片。没有把合成空白图当作真实街景泛化测试。
- 本轮追加DeepSeek或其他外部模型API调用为0；没有重写用户记录、清空历史或重置额度。

AI复核者就是实施本轮代码的助手，可能存在偏差。报告明确记录`kind=model`、`independent=false`、真人核对数为0，不发布“独立准确率”。

## 发现与处理

| 问题 | 处理 | 尚存边界 |
| --- | --- | --- |
| 持物短答丢失不确定理由 | 对“不确定且未见明显物品”的回答保留实际理由；强化左右手、小物件和遮挡检查提示 | 12.6秒截图手边有细小浅色轮廓，原模型可能漏看，不能因改了措辞就说视觉错误已被证明修复 |
| 复合回答重复描述肩背 | 默认短答只去掉完全重复的肯定描述；每项事实、理由、限制和引用保留 | 不合并不同编号，不删除否定或不确定条款 |
| 身高问题附带未询问的外观 | 标准纸张说明仅作为上下文；已有身高答案时禁止附带外观扩展；“服饰”直接归入衣着查询 | 明确询问外观时，模型仍可能误读眼镜等细节 |
| UW1的身高范围未覆盖作者标签 | 保留原始输出、误差和失败记录，继续标为实验性粗估 | 不回填真实身高，不把研究几何基线精度当作Agent精度 |

规则修改已有本地回归。对于短答去重和保留理由，额外复用了历史真实事实及视觉解读进行展示回放，原始事实值与引用未改变。它不是新的模型推理，也没有证明修改提示后视觉漏看已经消失。

旧聊天记录保持原样；新版本规则对新的回答生效。服务端回答缓存按实现版本失效，不能将旧缓存当作新模型验证。

## 可选真人后续

离线材料没有默认勾选“真人独立审阅”。只有实际审阅者亲自核对、填写代号及逐项判断后，才能导出真人评审记录。声明本身不是软件对真实身份的证明。自动化表单测试使用`test_fixture`，不计为真人意见。

后续如有真实评审记录，可导入：

```powershell
python evals/review_media_answers.py --catalog evals/ai-review-results.json --review path/to/Trace-human-review.json --height evals/measured-height-validation.json
```

导入时核对问题、原始回答和素材摘要；版本不一致时拒绝沿用评分。AI报告本身使用不同格式，不能作为真人评分导入。当前没有这一步的真实人工结果。
