# 本地上传扩容验收（2026-11-01）

页面恢复为精简前的完整版，保留证据复核、视频事件、自有素材三个入口。此次保留的功能变化为上传扩容：图片20MiB、视频200MiB且最长120秒。仍检查2000万像素尺寸上限和实际可解码格式，不接受无限长文件。

## 修改范围

前后端共用`data/media-limits.json`。同步修改文件选择校验、HTTP声明大小与实际流长度检查、视频元数据、规范化上限、600帧采样预算与实际进度。每个视觉任务最多300秒，FFmpeg子任务最多120秒，接收文件最多120秒；查询及补查的等待预算覆盖有界队列。只有本地上传素材的Agent等待预算扩大，原有模型调用次数、工具次数、单次供应商请求时限及公开视频案例预算保持不变。文件SHA256采用流式计算。

## 实测

使用已有署名许可的港口公开视频循环构造两分钟输入，按固定码率转码为45,178,885字节（约43.09MiB）。通过真实HTTP接口上传并运行本地YOLO11n，指定查找船；没有调用语言模型API。

- 输入完整性SHA256与任务结果一致。
- 实际时长120秒，处理600个5fps采样画面，末次采样119.8秒。
- 进度从100帧继续增长到600/600。
- 标注WebM实际600帧、5fps、时长120秒；最后一秒可解码。
- 上传、检测、下载及解码验证合计29.46秒，为当前机器及这份素材的结果。
- 验证完成后通过API删除临时任务，再次查询返回404。

[脱敏实测凭据](media-limits-validation.json)只含公开视频测试统计，不含会话、资源令牌或密钥。大文件测试制品留在被忽略的本地工作目录，不打入源码包。

76项后端与视觉规则测试、37项前端测试、类型检查和生产构建通过。包含20MiB/200MiB等号边界、超出一个字节、空文件、非法格式、120秒接受/120.2秒拒绝、HTTP头大小与流长度一致性，以及长媒体请求不会按短文本问答时限误判超时。
