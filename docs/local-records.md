# 本机识别记录与刷新恢复

2026-11-02，解决刷新需要重传文件、重选物体和无法返回以前分析的问题。

## 使用

完成分析后自动保存，无需另点保存。工作台右上角“识别记录”列出本浏览器拥有访问凭据的本机结果，包含缩略图、文件名、识别类别和时间。点击查看直接读取现有结果，不上传、不运行检测、不调用语言模型。“分析新素材”保留旧记录；“删除”才清除对应素材、副本、识别和聊天记录。

刷新当前页面会恢复结果、初选物体、所选编号和播放位置。分析前选好的文件通过浏览器IndexedDB暂存30分钟，刷新后可继续；文件分析完成后清理浏览器草稿。服务端处理中刷新继续查询原任务，不重新创建任务。临时连接失败展示重新连接，不将网络错误或服务503误判为文件已删除。

## 保存范围

- 已完成：保存在本机`work/uploads/{UUID}`，直到主动删除，服务重启后仍可查看。保留已分析版本和规范化素材，不保留已删除的原始上传与无用中间文件。
- 未完成/失败任务：沿用原有30分钟清理；孤立进程和取消清理规则不变。
- 浏览器：保存记录访问引用、初选类别及当前查看位置；草稿文件过期后在后续访问或写入时清理。浏览器不允许文件暂存时明确提示，当前页仍可分析，类别选择仍会保存。
- 历史迁移：磁盘上仍存在的旧完成结果迁移为保留记录；已经被旧版清理的文件不能恢复。

记录访问仍校验所有者凭据，不遍历展示其他浏览器会话的文件。`GET /api/uploads`只返回该凭据所属记录的轻量摘要，资源令牌仍仅访问作业白名单文件。实时提问另外使用有期限的会话和原有模型额度；读取、切换、删除历史不重置额度。上传功能仍只在本机SQLite运行模式开放，未开放公网或云同步。

## 验证

API测试覆盖完成记录跨清理/服务对象重建、所有者隔离、删除单条保留其他记录、记录访问与提问会话分离且不回退用量。前端测试覆盖普通刷新、新标签页、旧缓存迁移、存储异常回退、无效引用和网络错误分类。

独立浏览器实际重新分析公开道路40秒视频及其截帧，验证：

1. 分析前刷新恢复真实文件预览和人/汽车选择。
2. 识别中刷新继续同一任务。
3. 完成后刷新恢复选中编号及22.4秒播放位置。
4. 模拟恢复接口503，记录保留，重新连接后恢复。
5. 两条记录往返切换，无新增上传、识别或模型请求；分析新素材没有删除旧结果。
6. 空标签页缓存可从持久引用恢复当前结果。
7. 手机端记录列表无横向溢出；删除其中一条仍可返回另一条。

这次浏览器验证共2次真实上传、1次明确删除、0次模型请求，未发现页面脚本错误。测试原始素材为已有署名许可的公开道路样本，未保存用户私密文件为演示数据。私密缓存及访问凭据不包含在源码包中。
