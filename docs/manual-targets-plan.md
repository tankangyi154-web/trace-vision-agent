# 手动输入物体与取消示例

按用户要求直接调整现有本地工作台：移除上传页面的“用示例体验”及专用API；保留其他历史技术案例和素材。

手动输入是物体选择的主入口，支持中英文、常用叫法、逗号/顿号分隔及回车添加；列表改为辅助入口。名称解析为现有模型真实类别，明确显示规范名称；不把未支持名称伪装成可检测类别。最初仍需1—3种，留空不运行，追问补查保持原行为。正在编辑但未添加的输入阻止开始分析，避免漏掉用户正在填写的物体。

现有本机固定COCO权重只支持80类。用户所说YOLOv8还可采用其他训练数据或开放词汇模型；本轮不下载或替换模型，不宣称任意文字已可识别。未知名称就地提示当前不支持。
