2026-11-03。已对接两类公开来源，分别统计，不将几何模型精度当作Agent精度。当前Agent的身高回答仍为实验性粗估。

## 当前Agent：三张作者标注照片

来源为[HeightEstimator作者仓库](https://github.com/seanmiles/HeightEstimator)，固定版本`0441d2667f99892fe3e0beb99f6a70fe97b8f755`。README逐张给出“Actual”身高；`main.cpp`明确采用纸张8.5×11英寸、纸张与持有者处于相近距离的假设。作者没有公开实际测量流程，不能将这些标签说成本项目独立实测。

三张原始照片实际经过当前上传、YOLO识别、目标取图、DeepSeek看图、结构化校验链路。使用同一问题，给模型的只有纸张尺寸假设和身高问题，没有给被测人物的身高标签。尺码真值仅在返回后用于比较。没有按每张照片的误差调参。

| 用例 | 作者标注（厘米） | 实际Agent范围（厘米） | 区间中点绝对误差（厘米） | 标签是否落入范围 |
| --- | --- | --- | --- | --- |
| UW1 | 162.56 | 165—185 | 12.44 | 否 |
| UW2 | 180.34 | 170—185 | 2.84 | 是 |
| UW3 | 162.56 | 160—180 | 7.44 | 是 |

三例均完成并输出数值；区间中点MAE为7.57厘米，区间覆盖为2/3，拒答0例、执行失败0例。只有三张样本，且使用作者标注、参照尺寸假设，不能据此发布普适准确率或厘米级测量承诺。第一例超出了模型给出的范围，应保留为失败案例，不能只展示成功的两例。

实际回答还暴露了“参照尺寸说明被当成额外外观问题”的计划错误。现已将纸张尺寸和横竖说明作为上下文，不扩展成体型、持物、衣着查询；新增M33回归。修复使用本地测试，没有追加付费模型调用。因此这里保留的是当时真实数值输出，不假称已在修复后再次运行模型。

另补齐标准纸张参照：人物手中与自身处于相近距离的纸张可用`same_depth_plane`表示，不强迫纸张放在地面。仍要求完整清晰站姿、合理参照、宽范围及不确定标记；倾斜、遮挡、不同远近等限制保留。

### 调用记录

本次原计划最多3次模型调用。核验辅助脚本的补丁在请求前退出作用域，实际走了生产默认供应商，三个请求分别调用2、3、3次，共8次。发现后停止追加调用，按实际用量修正报告；没有把辅助计数器的零值当作实际用量。补丁现覆盖完整请求周期，可复现脚本默认只读报告，`--live`才允许外部调用，并限制每例至多一次、全批至多三次。若一次未完成，保留失败，不自动追加付费修正。

## 研究实测数据：独立几何基线

来源为[Li等人的CCVS论文与作者数据](https://github.com/lishengzhe/ccvs)，固定版本`2a1f45a29eeceb945d53410135535d5e6c87b408`。[论文第3.2节](https://doi.org/10.1186/s13640-015-0086-1)说明：人员在录像前穿鞋测量身高，并人工标注头脚位置。

本项目根据论文的三参数投影关系独立实现几何对照，没有运行作者提供的MATLAB或可执行程序。每个机位只使用参考人员001拟合相机参数，再对其余人员计算高度；测试人员的真实身高没有参与拟合。

| 项目 | 本机实际结果 |
| --- | --- |
| 机位 | 9个 |
| 测试人员 | 10名，均不含校准人员001 |
| 可用机位×人员组 | 88组 |
| 统计单位 | 每机位、每人员的多个观测均值 |
| MAE | 1.91厘米 |
| 最大组误差 | 10.80厘米 |
| 外部模型调用 | 0次 |

这使用**人工标注头脚点**，不包含YOLO框误差、跟踪串号或Agent看图误差。同一人员在不同机位重复出现，88组不是88个独立人员。未做镜头畸变校正，不声称复现了论文的具体精度。几何基线未接管普通上传的Agent回答，不能将1.91厘米写成产品身高精度。

仓库中的示例视频与已下载身高表不能可靠一一对应，未给该视频硬配真值，也未计入误差样本。需要登录的完整视频下载未使用。

结果：`evals/height-geometry-results.json`及`evals/measured-height-validation.json`。输入文件、固定来源和SHA256见`evals/height-data-sources.json`。

## 本机复现

下载器仅下载固定版本的文本与图片，校验长度及SHA256，不执行外部代码；原素材保留在已忽略的`work/`中。

```powershell
python scripts/fetch_height_validation.py
# 几何对照需要vision环境中已锁定的numpy/scipy
work/vision-env/Scripts/python.exe evals/run_height_geometry.py --data work/height-validation/ccvs --output work/height-validation/reproduced-geometry.json
python evals/review_media_answers.py --height evals/measured-height-validation.json
# 默认只读取已保存的Agent结果，不触发外部调用
python evals/run_height_images.py
```

`evals/run_height_images.py --live`会真正上传本机下载的公开样本至本机识别服务，并将提取的图片发送给已配置供应商。需先配置本机识别环境与服务端模型。它使用单独QA数据库和所有者，不重置正式会话额度，不修改已有用户记录；超过预算保留失败，不重发。

本轮完成的是可追溯的分层开发验证。后续用户选择先完成[AI证据复核](ai-evidence-review.md)，该范围已交付；没有真人意见，也不将AI复核标为人工评估。
