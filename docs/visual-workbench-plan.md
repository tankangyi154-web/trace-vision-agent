# 视觉工作台改版实施

依据用户已确认的`outputs/UI对标与改版建议.html`。以现有a0af3aa为本地可运行基线，沿用Vue与原API；不迁移框架、不安装模板依赖、不改模型、额度、缓存或补查规则。

设计：紧凑标题与单一工作区。先在左侧上传/预览，右侧填写1—3种物体；分析后左侧原位显示标注、目标和关键画面，右侧简短统计与问答。消息区独立滚动，用户向上阅读时不拉回底部，新回答通过提示进入。答案附真实证据缩略图。手机使用画面/问答切换，不卸载播放器或丢失上下文。控件统一44px以上操作目标、灰阶正文和蓝色主操作。

Ruling: 在当前干净的本地检出中创建功能分支，保留原分支基线；用户已要求在当前本地工作台直接实施，不另建需要复制私密配置与运行环境的工作树。
