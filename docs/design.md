# 视频事件分析 Agent · 已确认设计

面向招聘展示的独立项目。访客无需登录、安装软件或配置密钥，即可播放公开视频、核查事件证据，并使用受额度限制的实时 Agent 连续提问。

## 已确认选型

- Vue 3 / TypeScript / Vite；FastAPI；LangGraph 单 Agent；OpenAI 兼容工具接口。2026-10-31 用户追加选择 DeepSeek，默认 deepseek-flash 非思考模式，同时保留百炼 qwen-plus 配置支持。
- Vercel Hobby 托管前端和 Python API；Upstash Redis 持久化请求、会话和每日额度。未经授权不购买服务。
- YOLO nano + ByteTrack 仅在本地处理，输出真实轨迹、事件索引、证据与标注视频。线上无重视频推理。
- 曾比较 Streamlit 原型（休眠/唤醒影响招聘体验）与完整在线视觉推理（运行成本及冷启动过重），按已确认方案选择预处理视觉 + 实时 Agent。

## 页面及视觉

工作台首屏直接进入视频和对话，桌面两列，下方为事件时间线和证据；移动端单列。另有算法评测和实现说明。
底色 #F5F7FA，表面 #FFFFFF，文字 #142A43，主操作 #2455E6，事件 #B84F13，边线 #DCE3ED。中文使用系统等线/苹方，数字使用等宽字体；视频及证据是视觉中心，避免卡片堆叠。
清晰说明“视觉检测已预先完成，Agent 问答与事件统计实时执行”。原始/标注切换、区域选择、驻留阈值、时间定位、报告导出均须可操作。

## 边界及可信性

公开首版不接受上传。素材允许公开且记录来源、作者、许可、处理方式与 SHA256。开发 fixture 必须显著标记，不允许冒充真实数据。目标 ID 仅在片段内有效；遮挡恢复只是跟踪假设，不是身份识别。没有标定时不估计真实速度/距离；不推断违法、损伤或身份。
时间由帧号/fps确定；连续观测间隔超过容忍值时不累计未知时间。画面初始就在区域内的目标标为 initial_presence，不能声称“进入”。结束时尚未离开标为右删失。短暂漏检只称观测中断，遮挡是否成立由人工查看证据确认。

## 数据流

公开视频 → 本地检测/跟踪 → 归一化轨迹 JSON + 媒体 → 确定性事件计算 → 五个工具 → LangGraph 有界模型循环 → 校验引用 → 回答与可下载报告。
工具：search_events、get_track、calculate_dwell、get_evidence、retrieve_rules。规则以 BM25 检索，提供片段 ID。回答引用目标、时间和有效证据 ID；未知问题明确说明。

## 费用及失败行为

每会话 5 问、每日全站 50 问（环境变量可调）；每问最多 3 次模型调用/5 次工具调用。限制问题、历史、上下文、输出与超时，记录真实 token。幂等请求绑定会话及内容；原子额度预留及请求状态持久化。生产 Redis 或模型配置缺失时实时问答关闭，既有视频、统计和报告仍可使用。禁用 SDK 自动重试，重复点击复用请求；故障不伪造回答。
