# 本地交付验收 · 2026-10-31

本次范围按用户最新安排：先交付本地版本，稍后再授权上线。没有创建/推送公开GitHub仓库，没有发布Vercel，不把本地预览作为公网交付。

## 可直接体验

固定入口 http://127.0.0.1:8000 。`scripts/start.cmd` / `scripts/start.ps1` 可以从停止状态启动API，等待健康检查后再打开浏览器；已运行时复用本项目入口。
三个场景为有许可的真实视频：harbor / crossing / night，共428帧、2273观测、69条片段内ID轨迹，555条目标证据记录（同时间共享截图，不代表555张不同图片）。本地使用API实时重新计算区域事件，无需密钥。
