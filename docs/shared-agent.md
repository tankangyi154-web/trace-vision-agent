# 分享版的真实Agent与密钥隔离

Windows完整版包含本地Python、前端、CPU视觉环境、模型、FFmpeg和三个真实案例。下载者能上传自己的素材并使用问答；无需得到项目作者的供应商密钥。

## 数据与调用路径

素材上传、检测、外观关联、证据截图与记录保留在下载者电脑。数量、出现时刻、排名和引用仍由本地工具计算；LangGraph执行与结果校验也在本机。问答服务只接收本次有限上下文及需要分析的目标JPEG，不接收整段原始视频。应用页面对此做简短说明。

在线入口是`data/agent-service.json`中的公开URL。模型使用与开发环境相同的DeepSeek `deepseek-flash`。`PROVIDER_API_KEY`只作为Sites运行时secret设置，不出现在源码、前端、安装包、请求正文或客户端的Authorization中。客户端仅发送本机随机生成的体验身份；它不是供应商密钥。项目作者自己在本地配置供应商密钥时仍使用原来的直连路径。

## 云端强制额度

- 全站每天100次，每月1000次；日期按北京时间的日/月边界计算。
- 每份匿名体验身份一共10次，不按天重置。身份保存在本机`work/agent-identity.json`；浏览器刷新和正常重启不重置。
- 不要求HR登录。身份是一次安装生成的凭据，不能证明自然人唯一性；重新解压或主动修改客户端可生成另一份身份。全站每日/月总额仍在服务器上严格执行，不能靠修改客户端上限绕过。
- 每个有效新问题先原子预留一次额度，同一请求编号重试不重复计数；最多接受3次上游模型请求。失败或中断的已预留问题仍计一次，防止重复耗费；本机已保存回答可直接回看。
- D1事务批处理同时核对个人、日、月计数，并发请求不能透支。票据15分钟过期，禁止他人票据和外部图片URL；不允许客户端切换到更贵的模型。每次输出最多1800tokens，正文、工具定义和最多6张JPEG均有大小上限。
- 达到额度时只关闭新问答，上传识别、查看旧结果和导出不受影响。免费的是云端托管所用平台额度，DeepSeek实际推理仍消耗作者账号的可用额度。

服务端可通过`GATEWAY_ENABLED=false`暂停问答；修改云端环境变量后需发布已保存版本。密钥由所有者在云端Secret管理中更新，不应写入任何GitHub文件或客户端“加密配置”。

## 验证与发布

`deploy/agent-gateway`是可审查的完整Worker代码和SQL迁移。测试覆盖同问题幂等、个人总额、并发日限额、跨日月限额、每问题模型调用上限、外部图片拒绝及票据归属。API测试检查客户端只发送体验身份、额度错误不泄露供应商错误，以及并发创建身份的稳定性。

服务与完整版发布前还会检查：普通客户端不登录即可访问健康接口；新解压目录不含密钥仍能上传与真实问答；所有发行文件不含开发者密钥、数据库和个人识别记录。运行环境与跨硬件性能边界见`local-delivery.md`，不将测试通过率当作视觉准确率。
